# Chrome Web Store listing copy

## Name

X Shortcut Plus

## Short description

Configurable keyboard shortcuts for X feeds, pinned lists, and loading new posts without reloading the page.

## Detailed description

Navigate X feeds from your keyboard. X Shortcut Plus adds configurable shortcuts for For you, Following, and each pinned list.

This is a beta release.

FEATURES

• Jump directly to For you, Following, or a pinned list.
• Move to the next or previous feed in the displayed tab order, with wraparound.
• Scroll to the top and activate X's new-post banner with one shortcut. Without a banner, the action only scrolls. It does not reload the whole page.
• Assign, change, or clear bindings in extension settings. Changes apply to open X tabs.
• Keep list bindings when lists are reordered or renamed. Discovery is separated by X account.
• See warnings for known native X conflicts and duplicate bindings.

DEFAULT SHORTCUTS

For you: Ctrl+Alt+1
Following: Ctrl+Alt+2
Next feed: Ctrl+Alt+N
Previous feed: Ctrl+Alt+P
Top and new posts: Ctrl+Alt+K

Pinned lists have no default binding. Open X Home to discover them, then assign each list a shortcut in settings.

TYPING AND NATIVE CONTROLS

Shortcut actions pause in typing and IME composition contexts, visible dialogs and menus, and focused media controls. Browser, operating system, or other-extension shortcuts may take priority. Every binding can be changed or cleared.

LOCAL DATA

The extension stores settings, the observed X account username, and pinned-list metadata locally in your browser. It has no analytics, advertising, server, or private X API integration. It does not transmit this information to the developer or third parties. Read the privacy policy for the full description of local processing and retention.

BETA LIMITS

X's page structure and internal React tab keys can change. If a list ID cannot be identified, next/previous can still use its displayed tab, but the extension will not guess an individual persistent binding from its name or position. Banner wording outside the supported patterns may only scroll to the top.

X Shortcut Plus is an independent project and is not affiliated with or endorsed by X Corp.
