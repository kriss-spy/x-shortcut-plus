# Chrome Web Store listing copy

## Name

X Shortcut Plus

## Short description

Configurable X shortcuts for feeds, pinned lists, post authors, and account switching with reply restoration.

## Detailed description

Navigate X from your keyboard. X Shortcut Plus adds configurable shortcuts for feeds, pinned lists, post authors, and signed-in accounts.

This is a beta release.

FEATURES

• Jump directly to For you, Following, or a pinned list.
• Select feed positions 1–9 with Ctrl+Alt+1 through Ctrl+Alt+9.
• Open the selected post author’s profile with Ctrl+Alt+U.
• Switch to the next signed-in account with Ctrl+Alt+A. Restore the current URL, or the reply target and background page when replying.
• Move to the next or previous feed in the displayed tab order, with wraparound.
• Scroll to the top and activate X's new-post banner with one shortcut. Without a banner, the action only scrolls. It does not reload the whole page.
• Assign, change, or clear bindings in extension settings. Changes apply to open X tabs.
• Keep list bindings when lists are reordered or renamed. Discovery is separated by X account.
• See warnings for known native X conflicts and duplicate bindings.

DEFAULT SHORTCUTS

For you: Ctrl+Alt+1
Following: Ctrl+Alt+2
Next feed: Ctrl+Alt+N
Previous feed: Ctrl+Alt+P
Feed positions 3–9: Ctrl+Alt+3 through Ctrl+Alt+9
Selected post author: Ctrl+Alt+U
Next signed-in account: Ctrl+Alt+A
Load new posts: X’s native period (.) shortcut
Top and new posts: optional, unassigned by default

Pinned lists have no default binding. Open X Home to discover them, then assign each list a shortcut in settings.

TYPING AND NATIVE CONTROLS

Feed and author shortcuts pause while typing and using dialogs or media controls. Modified account shortcuts also work in media viewers and reply composers. All shortcuts pause during IME composition. Browser, operating system, or other-extension shortcuts may take priority. Every binding can be changed or cleared.

LOCAL DATA

The extension stores settings, the observed X account username, and pinned-list metadata locally in your browser. Account switching temporarily stores a return URL and account handles in per-tab session storage. Reply restoration also keeps the reply post ID and background URL. It does not transfer unsent text or attachments. It has no analytics, advertising, server, or private X API integration. It does not transmit this information to the developer or third parties. Read the privacy policy for the full description of local processing and retention.

BETA LIMITS

X's page structure, internal React tab keys, and reply router can change. If a list ID cannot be identified, next/previous can still use its displayed tab, but the extension will not guess an individual persistent binding from its name or position. Banner wording outside the supported patterns may only scroll to the top.
