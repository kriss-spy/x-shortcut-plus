# X Shortcut Plus 1.1.2-beta.1

Fixes account switching being canceled when opening the panel moves focus from a post into an account control. One `Ctrl+Alt+a` press should open the panel and select the next account.

The controller’s capture-phase `blur` listener received element blur events as well as window blur events. It canceled the pending account switch during ordinary focus changes. It now checks that the event target is the window before canceling. Leaving the browser window still cancels the pending switch.

The focus-transfer regression failed before this change and passes afterward. `npm test` passes 59 checks. A visible Chromium fixture focused a post, opened the panel, focused its alternative-account button, and switched with one real key combination. The fixture reloaded through Home and restored the exact return URL. Packaging checks passed.

These are regression and Chromium fixture checks. Live X confirmation remains pending. Chrome’s numeric version is `1.1.2`; its display version is `1.1.2-beta.1`.
