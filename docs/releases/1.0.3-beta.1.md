# X Shortcut Plus 1.0.3-beta.1

First public beta of the local Chrome extension for X feed shortcuts.

## Included

- Configurable shortcuts for For you, Following, and each discovered pinned list.
- Next/previous feed in displayed order, with wraparound.
- One shortcut to scroll to the top and activate X's new-post banner, without reloading the page.
- Local settings, live updates in open X tabs, native-conflict warnings, and duplicate-binding detection.
- Typing, IME, dialog, menu, and focused-media guards.
- Account-scoped list discovery and list-ID bindings that survive reorder and rename.

Current X Home tabs can be non-link `div` controls. This beta supports that markup and reads their `List:<id>` React keys locally. It makes no private X API requests and requires no server. The only extension permission is `storage`.

## Install

1. Download `x-shortcut-plus-1.0.3-beta.1.zip` from this release.
2. Extract the ZIP into a permanent folder.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Select **Load unpacked**, then select the extracted folder containing `manifest.json`.
6. Reload X and open Home.
7. Open the extension's settings to assign pinned-list shortcuts.

The ZIP is an unpacked extension, not a Chrome Web Store package. Keep its extracted folder in place. Existing testers can reload the extension using their current project `dist` folder to retain its extension identity and local settings. Loading a different folder can create a separate extension with separate settings; avoid enabling both copies.

## Provisional defaults

| Action | Default |
| --- | --- |
| For you | `Alt+Shift+1` |
| Following | `Alt+Shift+2` |
| Next feed | `Alt+Shift+ArrowRight` |
| Previous feed | `Alt+Shift+ArrowLeft` |
| Top and new posts | `Alt+Shift+ArrowUp` |
| Pinned lists | Assign in settings |

All bindings can be changed or cleared. Operating system shortcuts and other extensions can take priority.

## Validation and beta limits

All 33 automated checks passed. Packaged Chromium checks passed for direct bindings, `Ctrl+Alt+1`, list discovery across MAIN/isolated execution worlds, persistence, reorder/rename, stale-ID rejection, feed wraparound, typing guards, and the banner action without reload. The initial tester reported that build 1.0.2 worked; this beta adds release metadata and packaging to that implementation.

X's DOM and React keys can change. If a list ID cannot be confirmed, next/previous still includes that tab, but the extension will not invent a persistent binding from its name or position. Real IME sessions, macOS, other extensions, and every X rollout remain outside the completed live checks. See `docs/verification.md` for the full record.

The display version is `1.0.3-beta.1`; Chrome's numeric manifest version is `1.0.3`. Subsequent Chrome uploads must increase that numeric version.

Report failures with the browser and extension versions, action and binding, route, and whether focus was in an editor, dialog, or media control. Do not include passwords, cookies, tokens, or private post content.
