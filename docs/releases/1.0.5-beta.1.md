# X Shortcut Plus 1.0.5-beta.1

All five defaults now use Ctrl+Alt, matching the tester's updated bindings.

| Action | Default |
| --- | --- |
| For you | `Ctrl+Alt+1` |
| Following | `Ctrl+Alt+2` |
| Next feed | `Ctrl+Alt+n` |
| Previous feed | `Ctrl+Alt+p` |
| Top and new posts | `Ctrl+Alt+k` |
| Pinned lists | Assign separately in settings |

Shift is not part of these defaults. Saved custom bindings and explicitly cleared bindings are preserved. Actions with no saved override use the new defaults automatically. Previously saved Alt+Shift bindings remain assigned until changed in settings.

## Install or update

Download and extract `x-shortcut-plus-1.0.5-beta.1.zip`. Open `chrome://extensions`, enable Developer mode, and load the folder containing `manifest.json`.

For an existing installation, replace files in its existing unpacked folder, reload the extension in `chrome://extensions`, then reload X. Keeping the same folder retains the extension identity and local settings. Avoid enabling a second copy from another folder.

The Chrome manifest version is `1.0.5`; the displayed version is `1.0.5-beta.1`. Permissions and product scope are unchanged. No server or private X API is used.

## Validation and limits

All 33 automated checks pass with modifier-aware controller input. Packaged Chromium checks verify fresh-install defaults, real Ctrl+Alt key events for all five actions, feed cycling and wraparound, both banner states, typing protection, and preservation of saved and cleared bindings.

The browser/system warning remains visible for Ctrl combinations. It is a general caution, not proof of a specific conflict. Operating system shortcuts and other extensions may take priority; AltGraph and active IME composition remain protected.
