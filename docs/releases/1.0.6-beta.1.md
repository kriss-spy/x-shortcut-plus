# X Shortcut Plus 1.0.6-beta.1

Chrome Web Store preparation build. Keyboard behavior, Ctrl+Alt defaults, local storage, and permissions are unchanged.

- Added original PNG extension/toolbar icons at 16, 32, 48, and 128 pixels.
- Added a public privacy policy describing local account/list metadata and shortcut handling, with a disclosure and policy link in settings.
- Prepared two store screenshots, a 440×280 promotional tile, and a 1400×560 marquee image.
- Added copy-ready listing, permission explanations, and reviewer test instructions.
- Updated packaging to include nested icon files and validate their manifest paths.

The Chrome manifest version is `1.0.6`; the display version is `1.0.6-beta.1`.

## Upload files

Use `x-shortcut-plus-1.0.6-beta.1.zip` as the extension package. It contains `manifest.json` at its root. Store artwork and dashboard text are supplied separately in the store asset pack; do not upload that asset-pack ZIP as the extension.

Public privacy policy: https://github.com/kriss-spy/x-shortcut-plus/blob/main/PRIVACY.md

All 33 automated checks pass. Image dimensions, RGBA icon formats, manifest paths, JavaScript syntax, ZIP integrity, and package checksums were checked.

This build is prepared for submission. It has not been submitted to or approved by the Chrome Web Store.
