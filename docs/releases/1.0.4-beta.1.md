# X Shortcut Plus 1.0.4-beta.1

This beta ships the tester-approved default shortcuts.

| Action | Default |
| --- | --- |
| For you | `Alt+Shift+1` |
| Following | `Alt+Shift+2` |
| Next feed | `Alt+Shift+n` |
| Previous feed | `Alt+Shift+p` |
| Top and new posts | `Alt+Shift+k` |
| Pinned lists | Assign separately in settings |

Hold Shift while pressing each letter. Settings display the canonical lowercase letter alongside the Shift modifier.

Saved custom bindings and explicitly cleared bindings are preserved. Actions with no saved override use the new defaults automatically. Previously saved arrow-key bindings remain assigned until changed in settings.

## Install or update

Download and extract `x-shortcut-plus-1.0.4-beta.1.zip`. Open `chrome://extensions`, enable Developer mode, and load the folder containing `manifest.json`.

For an existing installation, replace files in its existing unpacked folder, reload the extension in `chrome://extensions`, then reload X. Keeping the same folder retains the extension identity and local settings. Avoid enabling a second copy from another folder.

The Chrome manifest version is `1.0.4`; the displayed version is `1.0.4-beta.1`. Permissions and product scope are unchanged. No server or private X API is used.

## Validation and limits

All 33 automated checks pass, with controller tests sending uppercase shifted letter events for the new defaults. Packaged Chromium checks verify fresh-install defaults, real `Alt+Shift+N`/`P`/`K` events, feed cycling, top-and-banner behavior, and preservation of saved and cleared bindings.

X's DOM and internal React list keys can change. Operating system shortcuts and other extensions may intercept combinations before X Shortcut Plus receives them. See [the full verification record](../verification.md) and [the first beta notes](1.0.3-beta.1.md) for other known beta limits.
