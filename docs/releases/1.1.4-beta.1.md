# X Shortcut Plus 1.1.4-beta.1

Preserves the reply target and background page when switching accounts from a reply composer.

Version 1.1.3 restored `/compose/post` as a URL. That reopened a new-post composer over Home. A reply also requires X’s `inReplyToStatusId`, `isSelfThreadReply`, and `previousPath` navigation fields. The account action now keeps those identifiers in its temporary return record, loads the original background page, then reopens the reply through X’s in-app router.

The MAIN-world script now contains a validated reply-navigation bridge. It accepts only a numeric post ID, a same-origin relative background URL, and the self-thread flag. It opens the composer after the background page is loaded. It never submits a post or copies draft text. If X’s router cannot be identified, the extension leaves the background page open instead of creating a blank composer.
